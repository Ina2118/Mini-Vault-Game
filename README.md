# Vault Game

A simple PIXI.js + GSAP vault unlocking game.

## Requirements

* Node.js installed
* Git installed

## Instructions

1. **Clone the Repository:**

```
git clone https://github.com/Ina2118/Mini-Vault-Game.git
```

2. **Navigate to the Project Folder:**

```
cd Mini-Vault-Game
```

3. **Install Dependencies:**

```
npm install
```

4. **Run in Development:**

```
npm run dev
```

5. **Build for Production:**

```
npm run build
```
