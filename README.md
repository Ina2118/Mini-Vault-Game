# Vault Game

A simple PIXI.js + GSAP vault unlocking game.

## Requirements

- Node.js installed

## Instructions

1. *Install Dependencies:*
   
   npm install
   
2. *Run in Development:*
   
   npm run dev
   
3. *Build for Production:*
   
   npm run build
   

Open the local server URL in your browser and check the developer console to find the combination!
